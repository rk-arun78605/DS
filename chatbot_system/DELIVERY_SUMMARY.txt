## 🆘 COMMON ISSUES - QUICK FIX

| Problem | Solution |
|---------|----------|
| `.env` not found | `copy .env.example .env` |
| API key invalid | Check https://platform.openai.com |
| Port 8000 in use | `taskkill /F /IM python.exe` |
| Database error | `pg_isready -h localhost -p 3307` |
| UI won't connect | Restart both services |
| Slow response | Reduce data: ask for "top 10" not all |
